# Проверка качества и сравнение подходов

Контрольный набор `eval/questions.jsonl` содержит восемь вопросов к трём синтетическим документам и четыре вопроса, на которые в корпусе нет ответа. Скрипт проверяет ожидаемое имя источника и фрагмент текста ответа, записывает длительность каждого вызова, cache hit и токены генерации при наличии usage. Для оценки ответов LLM вручную просмотри цитату и проверь, подтверждает ли она утверждение.

## Сравнение моделей OpenAI

1. Подними новый корпус, включи режим OpenAI и укажи первую модель в `OPENAI_CHAT_MODEL`. Для сравнения задержек выставь `CACHE_TTL_SECONDS=0`.
2. Запусти скрипт с теми же синтетическими документами и вопросами.

   ```bash
   python scripts/evaluate.py --label model-a --allow-external --output eval/results/model-a.json
   ```

3. Замени только `OPENAI_CHAT_MODEL` и пересоздай API через `docker compose up -d --force-recreate api`. Если запускал стек с `-p knowledge-openai`, укажи тот же параметр. Запусти скрипт с `--label model-b` и новым путём отчёта.
4. Сравни число корректных ответов и отказов, медиану времени, токены и цитаты. Сохрани названия моделей и условия запуска рядом с результатами.

## RAG в LangFlow

Для сравнения на тех же файлах собери штатный шаблон [Vector RAG](https://docs.langflow.org/chat-with-rag) в отдельном локальном проекте.

1. В цепочке индексации подключи Read File → Split Text → Vector Store. Загрузи файлы из `examples/`, сохрани имена файлов в метаданных, выбери отдельную коллекцию. Для сопоставимости используй ту же модель embeddings и зафиксируй способ нарезки.
2. В цепочке вопроса соедини Chat Input → Vector Store Search → Prompt → Language Model → Chat Output. В prompt передавай найденный текст вместе с именами источников и инструкцией отвечать только по этому контексту.
3. Для первых прогонов оставь не более пяти результатов поиска. Пройди вопросы из `eval/questions.jsonl` и отдельно выпиши случаи, где ответ оказался верным по смыслу, но источник отсутствует или указан неверно.
4. Зафиксируй время сборки и сравни, где гарантируются проверка источников, атомарная замена документа, тестирование отказов и контроль внешних запросов.

В этом репозитории Python реализует хранение, проверку и выполнение RAG. n8n автоматизирует приём файлов по вебхуку. LangFlow позволяет отдельно сравнить визуальную сборку RAG с этим вариантом. Контрольные измерения для двух платных моделей и запуска LangFlow заполняются после фактических прогонов.
